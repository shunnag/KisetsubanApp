# Kisetsuban

Kisetsubanは、エアロハス対応の家庭用サーバー（KisetsubanServer）と組み合わせて使う、Mac用のメニューバーアプリです。エアコンの運転状態と温度をメニューバーに表示し、近くにあるSwitchBot温湿度計の温度と湿度をBluetoothで受信してサーバーに送信します。

このリポジトリには、配布用のアプリとアップデート情報だけを置いています。

## 動作環境

- Apple siliconを搭載したMac
- macOS 26以降
- 同じネットワーク上で動作するKisetsubanServer（公開準備中）

## インストール

[Releases](https://github.com/shunnag/KisetsubanApp/releases)から最新のzipをダウンロードして開き、Kisetsuban.appを「アプリケーション」フォルダに移動してください。アプリはApple Developer IDで署名され、Appleの公証を受けています。以降のアップデートはアプリ内で自動的に確認されます。

It shows the air conditioner's state and temperature from a KisetsubanServer on the local network and can relay nearby SwitchBot thermo-hygrometer Bluetooth readings to it.
